# J.A.R.V.I.S.

Assistente pessoal com visual futurista, estilo Stark, pronto para funcionar em navegador celular e desktop.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Ou faça deploy em GitHub Pages / Netlify / Vercel.

## Funcionalidades

- Chat com interface futurista
- Botão de voz por microfone
- Respostas rápidas por comando
- Layout mobile-first
- PWA básico com manifest

## Importante

Este projeto é a versão front-end do assistente. Para ligar IA real (OpenAI, Claude ou Gemini), autenticação, banco de dados e integração com serviços reais, é necessário um backend em Python/Node.

## Publicação

Para publicar na web, use GitHub Pages ou Netlify. Para publicar na Play Store, é necessário converter para Android (Capacitor/Android Studio) e usar a conta do Google Play Console.
